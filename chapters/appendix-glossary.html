附录 A · 术语表 Glossary

全书 45 个核心术语的速查定义，按基础、编排、记忆与学习、保障与效率四组排列。

术语按全书使用口径定义，括号内为对应英文；"见第 N 章"指向主讲章节。定义压到一句话，求准不求全。

基础概念

术语 英文 一句话定义
智能体 Agent 能感知环境、自主决策、调用工具并朝目标行动的 LLM 驱动系统，核心是"模型 + 循环 + 工具 + 状态"（见第 5 章）。
工作流 Workflow 按预定代码路径编排 LLM 调用的流程，路径由开发者写死；智能体的路径由模型自己决定（见第 1 章）。
上下文窗口 Context Window 模型单次能读入的最大 token 量，是一切编排决策的硬约束（见第 8、16 章）。
上下文工程 Context Engineering 决定"哪一步让模型看到什么"的工程学科，比提示词工程范围更大（见第 1 章）。
系统提示 System Prompt 设定模型角色、边界与输出契约的常驻指令，护栏的第一道防线（见第 18 章）。
结构化输出 Structured Output 强制模型输出 JSON 等可校验格式，是步骤间可靠交接的契约（见第 1 章）。
幻觉 Hallucination 模型生成看似合理但与事实不符的内容；RAG 与反思模式的主要抑制对象（见第 4、14 章）。

编排模式族

术语 英文 一句话定义
提示链 Prompt Chaining 把复杂任务拆成顺序步骤链，前一步结构化输出作为后一步输入（见第 1 章）。
路由 Routing 按输入特征把请求分发给最合适的处理路径、模型或智能体（见第 2 章）。
切分 Sectioning 并行化变体：把独立子任务并发执行后归并（见第 3 章）。
投票 Voting 并行化变体：同一任务多次采样后多数投票，用方差换准确率（见第 3 章）。
自洽性 Self-Consistency 投票的学术原型：多次采样推理路径、归一化后计票（见第 3、17 章）。
反思 Reflection 生成-批评-修订的质量迭代循环，分自反思与外部反馈两条线（见第 4 章）。
工具使用 Tool Use 智能体经结构化接口调用外部 API/代码/数据，突破参数化知识边界（见第 5 章）。
函数调用 Function Calling 工具使用的 API 协议形态：模型输出符合 schema 的调用参数（见第 5 章）。
规划 Planning 先生成显式计划再执行、失败后重规划的闭环，计划-执行可分离也可交织（见第 6 章）。
多智能体协作 Multi-Agent Collaboration 多个角色化智能体经编排器/协议协同分工，换专业化与制衡（见第 7 章）。
编排者-工人 Orchestrator-Workers 多智能体拓扑：主智能体动态拆解派发，工人并发执行后归并（见第 3、7 章）。
模型上下文协议 MCP（Model Context Protocol） Anthropic 2024 年发布的工具/数据接入开放标准，"AI 应用的 USB-C"（见第 10 章）。
智能体间通信 A2A（Agent2Agent） Google 2025 年发布的 agent 互操作开放协议：能力名片 + 任务生命周期（见第 15 章）。
智能体名片 Agent Card A2A 里服务方自描述能力与端点的发现文档（见第 15 章）。

记忆与学习族

术语 英文 一句话定义
短期记忆 Short-term Memory 当前会话窗口内的对话状态，靠截断/摘要管理（见第 8 章）。
长期记忆 Long-term Memory 跨会话持久化的事实与偏好，靠检索注入生效（见第 8 章）。
情景记忆 Episodic Memory 按经历存储的"发生过什么"，Reflexion 用它存放语言化反思（见第 4、8 章）。
语义记忆 Semantic Memory 抽象化的知识事实，与具体经历分离（见第 8 章）。
记忆分页 Memory Paging MemGPT 提出的主上下文/外部上下文自主换页机制（见第 8 章）。
检索增强生成 RAG（Retrieval-Augmented Generation） 先检索外部知识再生成，抑幻觉、接私有数据的第一模式（见第 14 章）。
分块 Chunking 把文档切成适合检索的片段，粒度决定召回上限（见第 14 章）。
混合检索 Hybrid Retrieval 稀疏（BM25）+ 稠密（向量）双路召回再融合，抗单一检索失效（见第 14 章）。
重排 Rerank 用交叉编码器对初筛结果精排，花小钱买大精度（见第 14 章）。
查询改写 Query Rewriting 把用户原话改写成更适合检索的查询，HyDE 为代表（见第 14 章）。
学习与适应 Learning and Adaptation 智能体从经验反馈中持续改进提示、技能与策略的非参数化学习（见第 9 章）。
技能库 Skill Library Voyager 提出的可复用代码技能沉淀，学会的能力可检索复用（见第 9 章）。
进化循环 Evolutionary Loop 生成-评估-选择-变异的自动改进环，AlphaEvolve 为代表（见第 9、21 章）。

保障与效率族

术语 英文 一句话定义
护栏 Guardrails 约束智能体输入输出的安全机制层，纵深防御部署（见第 18 章）。
提示注入 Prompt Injection 用恶意指令劫持模型行为，间接注入经检索内容进体（见第 18 章）。
越狱 Jailbreak 绕过模型安全对齐的攻击，GCG 为自动化代表（见第 18 章）。
人在回路 Human-in-the-Loop 关键决策点引入人工审批，置信度不足时升级（见第 13 章）。
置信度升级 Confidence-based Escalation 低置信输出自动转人工或转更强模型（见第 13、16 章）。
异常恢复 Exception Recovery 重试、降级、检查点续跑的组合，从演示级到生产级的分水岭（见第 12 章）。
幂等性 Idempotency 同一操作重复执行结果不变，是安全重试的前提（见第 12 章）。
熔断 Circuit Breaker 连续失败后快速拒绝并等待恢复，防故障雪崩（见第 12 章）。
补偿事务 SAGA/Compensation 长流程失败后用反向操作回滚已完成步骤（见第 12 章）。
目标监控 Goal Setting and Monitoring 目标-判据-进度-偏差的反馈环，防目标漂移（见第 11 章）。
评估 Evaluation 离线断言、场景回归与在线 A/B 的质量度量体系（见第 19 章）。
LLM 裁判 LLM-as-Judge 用模型给输出打分，需消位置与冗长偏差（见第 19 章）。
测试时扩展 Test-time Scaling 推理期投入更多算力换正确率，推理模型的理论基础（见第 17 章）。
过程奖励 Process Reward Model 对推理每一步打分而非只看结果，过程监督优于结果监督（见第 17 章）。
级联 Cascade 先用便宜模型、置信不足再升级贵模型的成本优化策略（见第 16 章）。
语义缓存 Semantic Cache 按语义相似度命中历史答案，跳过重复推理（见第 16 章）。
提示缓存 Prompt Caching 供应商侧缓存重复提示前缀，按折扣计费（见第 16 章）。
优先级排序 Prioritization 有限资源下按依赖/截止/价值密度排序与抢占调度（见第 20 章）。
探索与发现 Exploration and Discovery 假设生成-自动验证-知识入库的开放域搜索循环（见第 21 章）。
探索-利用权衡 Exploration-Exploitation Tradeoff 试新选项还是吃老选项，多臂老虎机为数学模型（见第 21 章）。
